# Initial Major Release Fixture

This publicly distributed product currently uses SemVer `0.9.0`. The team has
approved `1.0.0` as its stable public-contract milestone. A stable version tag
is the release boundary.

`CHANGELOG.md`, `release-notes.json`, and the root package version share one
product release flow. The `1.0.0` notes should curate still-current capabilities
from public `0.x` history without deleting that history or implying those
capabilities all first appeared in `1.0.0`.
