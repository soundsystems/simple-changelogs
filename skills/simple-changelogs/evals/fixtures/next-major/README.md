# Next Major Release Fixture

This product uses SemVer. `main` is an integration branch, and merging to it is
not a release. Stable releases are published from version tags. The latest
stable release is `1.8.0`; `2.0.0-beta.2` is a public tester preview.

The root package, both changelogs, and `release-notes.json` share one product
release flow. The stable `2.0.0` notes should explain the transition from the
stable `1.x` line, preserve public beta history, and include the workspace-ID
migration without repeating unchanged `1.x` capabilities.
