# Skill-Repository Backfills

Backfill only after the current user or repository policy explicitly decides
the historical audit. Silence does not authorize reconstructing released
history.

Use tags, commits, package manifests, archived skill directories, published
packages, hosted releases, README install docs, and eval history as evidence.
State uncertainty rather than inventing versions, dates, shipped behavior, or
compatibility.

Safe drift repair can copy an unambiguous released value into an established
mirror, restore a missing generated packaged note, or remove an empty
`Unreleased` heading. Deleting, materially rewording, collapsing, moving
release boundaries, or changing the audience of released entries requires
explicit meaning-changing authority.

When an approved audit begins, record `partial`; set `completed` only after the
requested range and all established mirrors are verified. Use `failed`,
`deferred`, or `declined` only for the user's actual disposition.
